## 投稿手順（1本あたり2分）

1. `pipeline/out/YYYY-MM-DD/daily.mp4` をスマホに送る（`~/asus1/downloads/` 経由 or 直接アップ）
2. TikTokアプリで新規投稿 → 動画選択
3. キャプションは同フォルダの `caption.txt` をコピペ
4. 投稿時間の目安: **タイ時間 18:00–21:00**（日本時間 20:00–23:00）が占いジャンルのゴールデン
5. 音源: 動画に音声(TTS)入り。音量を下げてトレンド音源を薄く重ねるとリーチが伸びる（任意）

## 生成コマンド（leo上）

```bash
cd ~/apps/duangdee/pipeline && node gen-daily.mjs            # 今日(バンコク時間)分
cd ~/apps/duangdee/pipeline && node gen-daily.mjs 2026-09-05 # 日付指定
```

## 禁止事項（法務ライン）

- 「当たる保証」「絶対当選」等の表現は動画・キャプション・コメント返信すべてで禁止
- 宝くじの購入煽りをしない（เลขนำโชคは「開運の数字」として扱う）
- 動画内の「เพื่อความบันเทิง（娯楽目的）」表記は消さない
