# TikTok 日次分析の枠組み（2026-09-07 制定）

毎朝（JST 08:00 目安）に全動画の指標を取り、**率と差分**で見て、次の1手を1つだけ決める。感想ではなく指標→レバーの対応表で決める。

## 取る指標（動画ごと）
出所＝TikTok Studio の動画別インサイト `https://www.tiktok.com/tiktokstudio/analytics/<video_id>`（leo-windows レーン、ログイン済み）

| 指標 | 取り方 | 意味 |
|---|---|---|
| 視聴数 views | 概要 | 配信量（アルゴリズムがどれだけ回したか） |
| 平均視聴時間 avgWatch / 尺 | 概要 | **視聴維持率**＝avgWatch÷尺。TikTokが最も重く見る |
| フル視聴率 fullWatch% | 概要 | 完了率。ループ型は100%超もありうる |
| 離脱点 dropAt | 概要「〇:〇〇で停止」 | 0:01 なら「フック負け」、中盤なら「本文負け」、終盤なら「CTA負け」 |
| 新規フォロワー | 概要 | フォロー転換＝キャラ/シリーズ性 |
| 流入元 | 概要 | おすすめ％が低い＝テスト配信で落ちた／検索・プロフィールが伸びれば資産化 |
| いいね・コメント・シェア・保存 | エンゲージメント | 下の率に使う |
| 視聴者の地域・年齢・性別 | 視聴者 | **タイ比率**が最重要（日本アカウント問題の監視） |

## 率（毎日計算）
- 維持率 = avgWatch ÷ 尺（目安：短尺 ≥ 60%、40秒物 ≥ 35%）
- いいね率 = いいね ÷ 視聴（目安 ≥ 5%）
- コメント率 = コメント ÷ 視聴（目安 ≥ 0.5%。参加型は ≥ 1%）
- シェア率 = シェア ÷ 視聴（目安 ≥ 0.5%。自分事化型は ≥ 1%）
- 保存率 = 保存 ÷ 視聴（目安 ≥ 1%。資料型は ≥ 3%）
- フォロー転換 = 新規フォロワー ÷ 視聴（目安 ≥ 0.5%）
- 前日比の視聴増分（Δviews）：24h 以降に伸びているか＝二次配信に乗ったか

## 指標 → レバー（毎日「一番低い率」に対して1手）
| 症状 | 原因の仮説 | 打ち手 |
|---|---|---|
| dropAt = 0:01〜0:02、維持率 < 30% | 最初の1秒で自分事化できていない | フック文を「あなた＝〇曜日/〇年生まれ」型へ。文字を大きく、猫より文字先行 |
| 維持率は良いがフル視聴率が低い | 後半がだれる／尺が長い | 尺を短縮（3択型はリビール文を1文に）、末尾ループ化 |
| いいね率 低・維持率 高 | 見たが「共感の山」が無い | 一言の「見抜き」を強く（承認→本当の優しさ） |
| コメント率 低 | 問いが2つ以上／答えが長い | 問いを1つ、1語で答えられる形。ピン留めコメントで場を作る |
| シェア率 低 | 「誰かに送る理由」が無い | 「〇曜日生まれの友達に送って」を画面と読み上げ両方に |
| 保存率 低（資料型） | 情報が1画面で読み切れる／再訪価値が無い | 表を増やす（7曜日×3色）、来週分の予告 |
| フォロー転換 低 | 単発で終わる | シリーズ化（「明日は〇曜日」「9つの命 第n話」） |
| 視聴者の地域で日本が多い | 初期配信が日本寄り | 場所 Bangkok、タイ語タグ、タイ時間投稿の徹底。改善しなければタイ側アカウント検討 |
| おすすめ％が高いのに views が伸びない | テスト配信で落ちた | 上の率のどれかが閾値未満。最低の率を直す |

## 運用ルール
- 1日1手。同時に2つ変えない（効いた理由が分からなくなる）
- 5本ごとに型別の平均率を出し、勝ち型の投稿比率を上げる
- 数字は `pipeline/stats/tiktok-YYYY-MM-DD.json` に保存（`tools/tt-analyze.mjs` で率・差分を表にする）
- コメントは全件返信（แม่หมอ口調、問いかけ・再コメント要求はしない）
